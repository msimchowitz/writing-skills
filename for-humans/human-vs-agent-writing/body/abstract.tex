Agent prose can be grammatically clean and still feel wrong. The usual problem
is a missing reader. The answer works in general, but no one seems to need
this exact sentence. Ordinary facts get inflated, uncertainty disappears, and
every point receives the same weight. This guide explains those habits and
shows revisions that preserve the writer's facts and voice. The appendix keeps
the complete pattern catalog for reference. A later chapter considers several
possible causes, including next-token prediction, generic audience models,
mixed training data, code and documentation, and post-training incentives.
These are hypotheses, not findings. The patterns are useful for revision; they
do not establish authorship.

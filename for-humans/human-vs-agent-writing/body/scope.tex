\section{Patterns are useful for revision}
\label{sec:scope}

People write into situations. They anticipate an objection, select the fact
that is new to this audience, and keep the uncertainty that cannot honestly be
removed. An agent can imitate these choices. Without a clear audience, it
often produces a generic answer.

That is the distinction this guide cares about. Grammar, formal vocabulary,
and punctuation are weak evidence about the source of a passage. Human writers
use formulas; agents can write restrained, specific prose. A clean sentence
proves nothing about authorship.

\subsection{Name the reader}

Start an edit by naming the reader and the consequence of the document. A
reviewer checking evidence needs different details from a student learning a
mechanism. A collaborator choosing between two methods needs the comparison
early. Once that purpose is clear, the editor can judge each paragraph by the
new understanding or decision it gives that reader.

This test catches vague management language. ``Give each section one job''
sounds firm but explains little. ``Ensure each section helps the reviewer
answer one question'' gives the rule a reason.

\subsection{Describe the text, not the author}

Call a passage \emph{formulaic}, \emph{overstated}, or \emph{poorly sourced}.
Those claims can be checked. A claim about the person or system that wrote it
needs independent evidence.

Style-based detection produces familiar false positives. Professional editing
creates consistent grammar, word processors create curly quotation marks, and
fields develop shared vocabularies. A journalist may use many dashes. Look for
a cluster of choices that causes a reading problem rather than a lone tell.
